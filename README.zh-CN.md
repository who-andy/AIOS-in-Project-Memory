# AIOS in Project Memory

**即使 AI 忘记了，你的项目也能继续。**

这是一个开源 Agent Skill，让 AI 自主**设计、建立并持续维护长期项目记忆**。适用于长期学习、软件开发、研究和其他需要跨会话推进的任务。

你只需要说明想做什么。AI 会根据真实需求提问，自己判断应创建哪些文件，以及如何记录进度、决策和重要历史。

## 一条命令安装

```bash
npx skills add who-andy/AIOS-in-Project-Memory
```

想让 Skill 在多个项目中使用，可以全局安装：

```bash
npx skills add who-andy/AIOS-in-Project-Memory -g
```

指定安装到 Claude Code 和 Codex：

```bash
npx skills add who-andy/AIOS-in-Project-Memory -g -a claude-code -a codex
```

安装采用开源 [Skills CLI](https://github.com/vercel-labs/skills)，需要安装 Node.js 和 npm/npx。没有指定安装选项时，CLI 会引导选择目标 Agent 与安装范围。我们无需自行发布 npm 包。

想先查看仓库中识别到的 Skill：

```bash
npx skills add who-andy/AIOS-in-Project-Memory --list
```

> **重要：** 安装 Skill 只是让兼容的 Agent 能够读取这套方法。要真正跨会话持续保存记忆，Agent 还必须加载项目规则，并拥有对持久化项目目录的读写权限。对于无法访问的旧对话，模型无法凭空恢复。

## 能做什么？

| 功能 | 实际作用 |
| --- | --- |
| **自适应提问** | AI 询问必要的目标、约束和当前进度，不要求用户懂文件架构。 |
| **自主创建记忆** | AI 根据项目实际情况生成入口规则与记录文件，没有固定的领域模板。 |
| **持续记录** | 有可写目录时，在工作过程中及时保存重要反馈、决策、练习结果、测试及下一步。 |
| **跨 Session 恢复** | 新会话读取精简的当前状态，按需检索旧资料，避免每次从头解释。 |
| **中途接入已有项目** | 已经学了几个月或开发到一半，也能从可访问的旧对话与文件追溯进度。 |
| **跨工具迁移与演化** | 尽量使用人类可读的文件，项目结构可随任务演变调整。 |

## 快速开始

**1. 先自由讨论，最后正式初始化**

> 我们先讨论这个项目。等我说正式启动时，请使用 adaptive-project-memory，根据讨论内容建立长期记忆系统。文件结构由你决定。

**2. 从讨论一开始就保存重要内容**

> 使用 adaptive-project-memory 的 capture-only 模式，我们先自由讨论。请将有价值的信息及时保存到这个项目目录，等我说正式开始后再建立完整结构。

**3. 项目已经进行到一半**

> 我已经学了几个月，之前还有多个 Session。请使用 adaptive-project-memory，从你实际能访问的旧聊天、笔记、练习等材料恢复进度，标记缺失的资料，建立记忆系统，然后从当前进度继续。

**4. 直接初始化新项目**

> 请使用 adaptive-project-memory 为这个项目建立长期记忆。只问必要的问题，具体文件由你自主设计。

## 工作原理

```text
用户的目标与正常聊天
         |
Adaptive Project Memory
         |
理解需求 / 必要时追问
         |
AI 自主设计项目记忆结构
         |
AI 创建项目入口规则
(AGENTS.md / CLAUDE.md 等)
         |
未来 Session 恢复项目状态
    并持续保存重要进展
```

核心方法保存在 [SKILL.md](SKILL.md) 中。项目自己的入口规则和记录文件由执行 Skill 的模型生成，它会自行确定信息的保存位置、读取顺序和更新方式。

你可以先正常 Brainstorming，之后再正式初始化。如果希望讨论阶段的重要内容也能持久保存，需要在这些内容出现之前启动 capture-only 记录。

## 已有项目如何接入？

Retroactive Onboarding（追溯初始化）已经包含在 Skill 中。

AI 会从**当前确实可以访问、且用户授权使用**的旧聊天、文档、试题记录、代码和其他材料中重建进度，区分已验证与待核实信息，保留历史矛盾与资料缺口。后续发现更多旧记录时，还可以逐步补录。

你无须一次提供全部聊天记录。对于其他平台或当前无法访问的历史 Session，仍需要适当导出或提供相关内容。即使历史恢复不完整，也可以继续当前项目。

## 环境要求与注意事项

这是以 Prompt 为核心的 Skill，未强制要求后台服务或数据库。具备持久文件读写能力、能够在新会话加载项目入口规则的 AI 开发工具会更适合。

- **Claude Code / Codex：** 可以使用上面的 Skills CLI 安装，并在授权的项目工作目录中使用。
- **其他兼容 Agent：** 自动识别规则与写入能力依赖各个平台的实现。
- **无持久化文件权限的聊天工具：** 可以生成待保存的记录，但无法直接修改你电脑上的文件。

系统应验证文件是否真正写入，并如实报告失败情况。个人学习记录和项目历史应保存在私有目录，未经明确授权切勿上传至公开 GitHub 仓库。
